# 차곡 · 나의 가계부

데스크톱과 태블릿에서 사용하는 가벼운 개인 가계부입니다. 회원가입, 금융 연동, 외부 API 없이 기록을 현재 기기에 저장합니다. HTML·CSS·Vanilla JavaScript로 작성한 웹 화면을 Android 앱에서도 사용합니다.

[원본 기획서](https://app.notion.com/p/3fdf445d30e38049a01ed95b5e047551) · [개발 기준](docs/DEVELOPMENT.md) · [수동 확인 안내](docs/MANUAL_REVIEW.md)

현재 작업에서 생성한 파일은 로컬 `artifacts/` 폴더에 있습니다. `chagok-preview.apk`는 설치 가능한 미리보기 앱이며, `chagok-release-unsigned.apk`는 정식 서명 전 파일입니다. `chagok-web.zip`에는 웹 배포용 `dist/` 폴더가 들어 있습니다. 생성 파일은 Git에서 제외하며 코드를 수정한 뒤에는 다시 빌드해야 합니다.

## 시작하기

Node.js 20.11 이상을 사용합니다. 별도로 설치할 웹 패키지는 없습니다.

```sh
npm run dev
```

브라우저에서 `http://127.0.0.1:4173`을 엽니다. 파일을 직접 더블 클릭하는 방식은 저장소와 모듈 실행 조건이 다르므로 사용하지 않습니다.

1. **내 계좌 모음**에서 통장 이름과 현재 잔액을 등록합니다.
2. **설정 및 데이터 관리**에서 월 수입과 목표 저축액을 설정합니다.
3. **고정비 스케줄러**에서 매달 나가는 돈을 등록합니다.
4. **돈 쓰기 / 벌기**에서 거래를 기록합니다.
5. **메인**과 **지출 분석**에서 예산과 소비를 확인합니다.

## 기능

| 화면 | 제공 기능 |
| --- | --- |
| 메인 | 총 자산, 오늘 남은 예산, 월 수입·지출, 목표 저축액, 최근 지출, 남은 고정비 |
| 돈 쓰기 / 벌기 | 계좌별 수입·지출, 날짜·카테고리·감정 태그 입력 |
| 내역 보기 | 월별 조회, 내역·계좌 검색, 유형·카테고리·감정 필터, 수정·삭제 |
| 지출 분석 | 전월 동기간 비교, 카테고리 상위 5개, 소비 속도, 낭비 지출 |
| 내 계좌 모음 | 계좌 등록, 잔액 조정, 대표 계좌 지정, 보관·복원 |
| 고정비 스케줄러 | 반복 지출 등록, 월별 납부, 반복 중단, 미납 금액과 가용 자산 |
| 설정 및 데이터 관리 | 가계부 이름, 월별 목표, JSON 백업·복원 |

데스크톱과 태블릿 가로 화면에는 왼쪽 세로 메뉴를 표시합니다. 태블릿 세로 화면에서는 상단 메뉴 버튼으로 여섯 메뉴를 엽니다. 작은 화면에서는 카드를 한 열로 배치하고 거래 표 영역만 가로로 스크롤합니다. 화면을 16:9로 고정하지 않습니다.

## 예산 계산 기준

```text
월 변동비 예산 = 설정 월 수입 - 목표 저축액 - 월 고정비
오늘 권장 예산 = (월 변동비 예산 - 어제까지의 변동 지출) / 오늘 포함 잔여 일수
오늘 남은 예산 = 원 단위로 내림한 오늘 권장 예산 - 오늘 변동 지출
실제 가용 자산 = 현재 총 자산 - 조회 월 미납 고정비
```

고정비는 예정일만으로 출금하지 않습니다. 납부를 기록할 때 계좌와 지출 통계에 반영합니다. 이미 확보한 고정비를 변동비 예산에서 다시 차감하지 않습니다. 고정비 납부 금액을 수정하면 해당 월의 고정비 예산도 변경됩니다.

잔액 직접 수정은 조정 거래로 남기며 수입·지출 통계에서 제외합니다. 보관한 계좌의 잔액도 총 자산에 포함합니다. 실제 수입과 설정 월 수입은 별도로 관리합니다.

## 저장과 백업

- 웹 데이터는 해당 브라우저의 `LocalStorage`에 저장합니다. APK 데이터는 앱의 WebView 저장소에 저장합니다.
- 서로 다른 기기, 브라우저, 웹과 APK 사이에는 자동 동기화가 없습니다.
- JSON 백업을 내보내고 다른 환경에서 불러와 기록을 이동합니다. 불러오기는 현재 기록을 전체 교체합니다.
- 브라우저 사이트 데이터 삭제, 비공개 탐색 종료, 앱 데이터 삭제 또는 앱 제거로 기록을 잃을 수 있습니다.
- 백업 파일은 암호화하지 않은 금융 기록입니다. 사용자가 선택한 안전한 위치에 보관합니다.
- 저장 실패나 손상 데이터는 자동 초기화하지 않습니다. 손상 원본 내보내기와 정상 백업 복원을 제공합니다.
- 여러 탭을 동시에 편집하면 변경 안내를 표시하고 오래된 상태의 저장을 거부합니다. 여러 탭 사이의 완전한 동시 트랜잭션을 제공하지는 않습니다.

## 웹 배포 파일

```sh
npm run build
```

생성된 `dist/`가 정적 웹 배포 파일입니다. 하위 경로 배포를 지원합니다. 첫 온라인 접속에서 화면 캐시가 준비된 후 같은 주소를 오프라인으로 다시 열 수 있습니다. 배포마다 파일 내용으로 캐시 버전을 갱신합니다.

`.github/workflows/pages.yml`에 GitHub Pages 배포 절차를 준비했습니다. 저장소의 Pages 배포 소스를 **GitHub Actions**로 설정한 후 `main` 브랜치에 반영하면 배포합니다. 현재 작업에서 원격 저장소에 푸시하거나 공개 배포하지는 않았습니다.

## Android 앱

Android Studio에서 `android/` 폴더를 엽니다. JDK 17 이상, Android SDK 36, Gradle 8.14.3을 사용하며 Android 8.0 이상을 대상으로 합니다. 기기의 Android System WebView는 최신 버전 사용을 권장합니다.

```powershell
cd android
.\gradlew.bat :app:assembleDebug
```

Gradle이 빌드 전에 `web/` 내용을 앱에 자동으로 포함합니다. `local.properties`에는 사용하는 환경의 SDK 경로를 설정합니다. Android Studio가 SDK를 선택하면 이 파일을 생성합니다.

- 기본 미리보기 APK: `android/app/build/outputs/apk/debug/app-debug.apk`
- 미리보기 앱 ID: `io.chagok.accountbook.dev`
- 정식 앱 ID: `io.chagok.accountbook`
- 정식 릴리스: `:app:assembleRelease`로 서명하지 않은 APK를 생성합니다. 정식 배포 서명은 별도로 설정합니다.
- OneDrive 등에서 빌드 캐시 파일이 잠기면 `-PchagokBuildRoot=절대경로`로 새 빌드 경로를 지정할 수 있습니다.

앱에 화면 파일을 포함하여 첫 실행부터 인터넷 없이 사용할 수 있습니다. 인터넷 권한을 요청하지 않으며 외부 페이지 로딩을 차단합니다. JSON 파일 입출력은 Android 파일 선택기를 사용합니다. 앱 자동 백업과 기기 간 자동 이전은 비활성화하고 명시적인 JSON 백업을 제공합니다.

## 폴더 구성

```text
web/                  웹 화면, 계산 로직, 저장소, 오프라인 캐시
android/              로컬 웹 화면을 포함하는 Android 앱
scripts/              개발 서버, 웹 배포 파일 생성, Android 파일 준비
tests/                기존 계산·저장 테스트 코드
docs/                 개발 기준과 수동 확인 안내
.github/workflows/    GitHub Pages 배포 절차
```

사용자 요청에 따라 이후 기능 확인은 수동으로 진행합니다. 기존 자동 테스트 코드는 보관하며, 배포 절차에서는 웹 파일 생성만 수행합니다.
