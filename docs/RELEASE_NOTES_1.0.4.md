# 차곡 1.0.4

## 변경 내용

- 계좌를 추가할 때 사용 목적 대신 은행 이름을 입력합니다. 국민은행, 농협은행, 카카오뱅크처럼 입력하면 됩니다.
- 계좌 수정 화면에서도 은행 이름을 변경할 수 있습니다. 기존 등록 이름을 임의로 은행 이름으로 바꾸지 않습니다.
- 같은 은행을 여러 개 등록하면 순서 번호로 구분합니다. 거래 입력과 조회에서도 같은 표시를 사용합니다.
- 메뉴에 사용법 페이지를 추가했습니다. 은행 등록, 목표 설정, 고정비, 수입·지출, 내역 수정, 분석 순서로 안내합니다.
- 처음 사용하는 계좌 화면과 빈 메인 화면에 사용법 보기 버튼을 추가했습니다.
- 골드 디자인과 기존 가계부 저장 공간을 유지합니다.

## 설치 파일

설치용 파일은 `chagok-v1.0.4.apk`입니다. 정식 서명 전 파일을 설치용으로 배포하지 않습니다.

기존 앱 위에 같은 서명의 APK를 업데이트 설치하면 기존 기록을 이어서 사용합니다. 앱을 삭제한 뒤 재설치하면 앱에 저장된 기록도 삭제됩니다. APK 파일이 설치되기 전에 기존 앱을 자동으로 삭제하는 기능은 제공할 수 없습니다.

## 확인 범위

웹 파일 생성과 Android 미리보기·서명 전 릴리스 APK 빌드가 성공했습니다. 자동 테스트와 기기 검증은 사용자 요청에 따라 실행하지 않았습니다. 기능과 화면의 최종 확인은 사용자가 직접 진행합니다.
