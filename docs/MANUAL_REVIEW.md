# 수동 확인 안내

자동 검증은 추가로 실행하지 않는다. 아래 항목은 사용자가 직접 확인할 때 참고한다.

## 화면

- 데스크톱에서 왼쪽 메뉴와 카드가 겹치지 않는지 확인한다.
- 태블릿 가로·세로 방향에서 여섯 화면과 설정 화면을 연다.
- 태블릿 세로 화면에서 메뉴를 열고 닫으며 이동한다.
- 긴 계좌 이름과 큰 금액을 입력하고 본문 전체가 가로로 밀리지 않는지 확인한다.
- 거래 표는 표 영역 안에서만 가로로 이동할 수 있는지 확인한다.

## 사용 순서

1. 계좌 두 개를 등록하고 대표 계좌를 변경한다.
2. 월 수입과 저축 목표를 설정한다.
3. 지출과 수입을 기록하고 계좌 잔액을 확인한다.
4. 거래의 금액과 연결 계좌를 수정하고 잔액을 확인한다.
5. 거래를 삭제하고 잔액과 통계가 함께 바뀌는지 확인한다.
6. 잔액을 직접 조정하고 수입·지출에는 포함되지 않는지 확인한다.
7. 낭비 태그를 기록하고 내역 필터와 지출 분석에서 조회한다.
8. 고정비를 등록하고 납부 전후 잔액·미납 금액·변동비 예산을 확인한다.
9. 고정비 반복을 중단하고 과거 납부 기록이 유지되는지 확인한다.
10. 백업 파일을 내보내고 다른 브라우저 또는 APK에서 불러온다.
11. 창이나 앱을 닫은 뒤 다시 열고 기록을 확인한다.
12. 웹은 캐시 준비 후, APK는 설치 후 인터넷 없이 실행한다.

## 유의할 점

백업 복원은 현재 기록을 교체한다. 별도 브라우저나 미리보기 앱에서 확인하거나 기존 기록을 먼저 백업한다. 미리보기 APK와 정식 APK는 서로 다른 앱이므로 데이터를 옮길 때 JSON 백업을 사용한다.
